1日1回の運用セッションで最初に読み、最後に更新する。状態はここに集約する。

## 毎回の手順

1. このファイルの「現状」「バックログ」「ログ」を読む。
2. 数字を見る（Search Console の表示回数・クリック・掲載順位、Cloudflare Web Analytics のPV）。週1回は必ず記録する。Search Console は `search-console` スキルで取得する（キーチェーンの項目名は `gsc-sqlrenshu`、サイトは `sc-domain:sqlrenshu.com`）。
3. バックログの先頭から、その日に終わる大きさの施策を1〜2個実施する。
4. `pnpm test` と `pnpm build` を通し、コミット、プッシュ、`pnpm deploy` まで行う（デプロイは 2026-11-13 にユーザーが許可）。デプロイ後に本番URLで変更を確かめる。
5. 「ログ」に、やったこと・数字・次回の一手を3行以内で書く。
6. `discord-notify` スキルで、その日のまとめ（やったこと、数字、ユーザーへのお願い）を Discord に送る。
